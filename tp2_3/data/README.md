# Données

- `consumer_complaints.csv` : fichier brut du jeu Kaggle [`cfpb/us-consumer-finance-complaints`](https://www.kaggle.com/datasets/cfpb/us-consumer-finance-complaints)
  (CFPB, domaine public). Non versionné (volumineux) : placez-le ici ou laissez le notebook le télécharger avec `kagglehub`.
- `complaints_prepared.csv.gz` : jeu préparé (réclamations avec texte, classes regroupées, texte nettoyé), généré par le notebook (section 3.6).
